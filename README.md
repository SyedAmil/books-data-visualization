# Books Data Visualization

Charts and a dashboard built from 1000 books scraped from books.toscrape.com, using Matplotlib and Seaborn.

## What it shows
- Number of books per rating
- Price distribution
- Price by rating
- Heatmap of price bands vs ratings
- `data_story.md`: key insights in simple language

## Files
- `visualize_books.py`: script that makes all charts
- `books_viz_data.csv`: dataset
- `dashboard.png`: all charts on one page

## Run
pip install pandas matplotlib seaborn
python visualize_books.py
